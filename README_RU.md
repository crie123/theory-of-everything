## Обзор

WTF симулирует космологическую эволюцию из первых принципов, используя два взаимосвязанных системы:

- **SPH облака** — макрочастицы, представляющие газовые облака с коллективной термодинамикой (температура, плотность, давление). Каждое облако представляет N микрочастиц.
- **Узлы работы** — абстрактные источники поля, которые направляют химию и формирование структур. Аналогичны потенциальным ямам гравитации / ореолам тёмной материи.

Симуляция автоматически проходит 8 космических эпох в зависимости от номера итерации. Формирование структур — нейтрино → водород → звёзды → галактики → чёрные дыры — возникает из взаимодействия этих двух систем без жёстко закодированных результатов.

**Ключевое открытие разработки:** без точно настроенных параметров вероятность случайного образования близка к нулю. Стабильные структуры требуют контролируемого начального всплеска энергии (зажигание пролёта узла), который запирает материал внутри новообразованного пузыря вселенной.

## Основные концепции

### Облака vs частицы

Двигатель использует объекты **Cloud** вместо точечных частиц. Каждое облако является SPH макрочастицей с:

| Поле | Описание |
|------|---------|
| `pos` | Позиция центра масс (3-вектор) |
| `vel` | Скорость дрейфа |
| `mass` | Полная заключённая масса |
| `T` | Температура — прокси внутренней энергии |
| `rho` | SPH плотность (пересчитывается каждый шаг) |
| `P` | Давление = (γ−1)·ρ·T |
| `cs` | Скорость звука = √(γ·P/ρ) |
| `el` | Доминирующий элемент: `nu e p n H He C O Fe Ni` |
| `kind` | `cloud \| star \| whitehole \| bh` |
| `N` | Число представляемых микрочастиц |

Это означает, что химия и коллапс Джинса происходят на **уровне облака**, а не на уровне отдельных частиц. Одно облако H с достаточной массой и плотностью коллапсирует в звезду.

### Узлы работы

Узлы работы — это источники поля, которые катализируют химию и притягивают материю. Они не являются частицами — они не имеют массы и не взаимодействуют с SPH силами. Существует два типа:

- **Доминирующие узлы** (`primary`) — мощные (сила ×6), взаимно отталкивающие, действуют как прототипические ореолы тёмной материи галактик. Разделяются на разные пространственные области при создании.
- **Спутниковые узлы** (`secondary/tertiary/exotic`) — более слабые, засеиваемые внутри пузырей, в итоге поглощаемые ближайшим доминирующим.

Сила узла медленно затухает. Узлы накапливают работу, которую затем отдают близлежащим облакам, снижая эффективные пороги сборки.

### Энергетический баланс

Симуляция имеет конечный **Framework Reservoir** (по умолчанию 20M единиц). Он подаёт новые нейтринные облака с установленной скоростью. Когда резервуар опустошится, новый материал не поступает. Существующие пузыри могут продолжать развиваться. Это моделирует конечную энергию закрытой системы.

### Поток данных за шаг

```
spatial_hash.build()          → O(1) запросы соседей для всех последующих операций
sph_density_pass()            → установить rho, P, cs для всех облаков (векторизовано)
framework_feed()              → инъекция новых облаков nu из резервуара
white.process()               → белая дыра обрабатывает близлежащие облака
cloud.update()                → SPH силы + расширение Хаббла + охлаждение
assemble()                    → эпоха-зависимая химия: nu→e→p→H→He→...
accretion_fast()              → чёрные дыры поглощают близлежащие облака
collide_all_fast()            → столкновения облаков + слияние
merge_clouds()                → перекрывающиеся облака объединяются (консервация массы/импульса)
split_cloud()                 → фрагментация Джинса массивных облаков
spawn_multiverse()            → зажигание пролёта узла → новый пузырь вселенной
internal_nodes()              → засеивание новых узлов работы внутри существующих пузырей
update_nodes()                → дрейф узлов (эпоха-зависимо) + затухание
node_interactions_in_bubbles()→ отталкивание доминирующих + поглощение спутников
universe_evolution()          → эволюция радиуса и энергии пузыря
cosmic_epoch_events()         → события эпохи: рекомбинация, звёзды, галактики
universe_feedback()           → пузыри нагревают внутренние облака
interact_universes()          → гравитация пузырей привлекает близлежащие облака
node_gravity()                → узлы работы притягивают собранную материю
phase_walls() / space_decay() → граничные условия
```

## Космические эпохи

Эпохи автоматически продвигаются на основе номера итерации. Каждая эпоха включает специфичную физику:

| ID | Старт итер | Название | Ключевая физика |
|----|-----------|----------|-----------------|
| 0 | 0 | 💥 Большой взрыв / КГП | Горячая плазма, узлы на макс скорости дрейфа, доминирует nu |
| 1 | 30 | ⚛️ Нуклеосинтез | Скорость H→He ∝ ρ² (зависит от плотности); охлаждение ~a⁻² |
| 2 | 80 | 🌑 Рекомбинация | p+e⁻→H усиленно от плотности; охлаждение ~a⁻¹ |
| 3 | 150 | 🌟 Первые звёзды (Pop III) | Массивные звёзды без металлов у доминирующих узлов |
| 4 | 220 | ☀️ Реионизация | УФ от звёзд ионизирует окружающие облака H (H→p) |
| 5 | 300 | 🌌 Первые галактики | Начало отслеживания сборки галактик; метрика стабильности |
| 6 | 450 | 🔥 Космический полдень | Пиковое звёздообразование; дополнительное засеивание узлов |
| 7 | 650 | 🪐 Современная вселенная | Медленная эволюция; доминирование тёмной энергии |

Скорость дрейфа узлов (`NODE_DRIFT_BY_EPOCH`) падает в ~20 раз от эпохи 0 к эпохе 3, моделируя переход от доминирования радиационного давления к якорению узлов тёмной материей.

## Классы

### `Cloud`

Базовая макрочастица. Представляет газовое/плазменное облако.

```python
Cloud(pos, mass, radius, kind="cloud", el="nu", temperature=None, N=1)
```

**Ключевые методы:**

| Метод | Описание |
|-------|---------|
| `update(others, dt, nodes, epoch)` | Применить SPH силы, дрейф Хаббла, охлаждение |
| `cool(dt, epoch)` | Охлаждение Хаббла + радиативное; γ переключается в эпохе 2 |
| `update_thermo(epoch)` | Пересчитать P, cs из текущей rho, T |
| `set_density_from_neighbors(pos_arr, mass_arr)` | Векторизованная SPH плотность |
| `_pressure_visc_force(neighbors)` | Градиент давления SPH + вязкость Монаньяна |
| `_gravity_force(neighbors)` | Дальнодействующая гравитация от SPH соседства |

`energy` — свойство-псевдоним для `T`, сохранено для обратной совместимости.

---

### `WhiteHole(Cloud)`

Центральный источник энергии. Обрабатывает облака, попадающие в `WHITE_RADIUS`:
- Выбрасывает их наружу с ускорением скорости
- Нагревает их (`T += 5` за контакт)
- Преобразует чёрные дыры в взрывы облаков (`explode_bh`)

```python
WhiteHole(pos=[0,0,0])
```

---

### `BlackHole(Cloud)`

Объект сингулярности. Аккрецирует близлежащие облака, может взорваться при перегреве.

```python
BlackHole(pos)
```

| Метод | Описание |
|-------|---------|
| `accrete(b)` | Поглотить облако: добавить массу + тепловую энергию |
| `update_bh(world)` | Баланс работы внутри/снаружи; триггер взрыва при `BH_EXPLODE_E` |

Порождается автоматически, когда локальная плотность работы превышает `CRITICAL_WORK_DENSITY` (по умолчанию 120).

---

### `WorkNode`

Абстрактный источник поля. Нет массы, не SPH частица.

```python
WorkNode(pos, strength, node_type="primary", origin="void")
```

| Поле | Описание |
|------|---------|
| `strength` | Интенсивность поля; растёт медленно с накопленной работой |
| `node_type` | `primary` (доминирующий ореол) / `secondary` / `tertiary` / `exotic` |
| `life` | Коэффициент затухания 0→1; первичные узлы затухают медленнее |
| `drift_vel` | Скорость пространственного дрейфа; эпоха-зависимо |
| `_epoch` | Текущая эпоха, внедрённая `update_nodes()` |

Узлы не обновляются SPH. Они дрейфуют независимо, засеивая поля химии там, где проходят через кластеры облаков.

---

### `UniverseBubble`

Карманная вселенная, образованная зажиганием пролёта узла.

```python
UniverseBubble(center, btype="H")  # btype: "H" | "He" | "exotic"
```

| Поле | Описание |
|-------|---------|
| `radius` | Растёт при star_count ≥ 3, сжимается при истощении энергии |
| `energy` | Топливо; истощается внутренней работой + стоимостью радиуса |
| `star_count` | Звёзды внутри `max(radius, 6.0)` |
| `stability` | 0–1; падает при потере звёзд, растёт при сборке галактики |
| `peak_work_density` | Высочайшая плотность работы, наблюдаемая внутри (индикатор коллапса) |
| `bh_id` | `id()` центральной чёрной дыры если коллапс её произвёл |
| `collapse_count` | Сколько событий коллапса произошло |

Максимум одновременно активных пузырей: `MAX_BUBBLES = 12`.

---

### `SpatialHash`

Единообразная сетка для O(1) запросов соседей. Перестраивается каждый шаг.

```python
spatial_hash.build(bodies)
spatial_hash.query_radius(pos, radius)  → список тел
```

Размер ячейки: 4.0 единиц. Все операции SPH, гравитации, коллизии и аккреции используют это вместо O(n²) всепарного поиска.

## Физические функции

### SPH

| Функция | Описание |
|---------|---------|
| `sph_density_pass(world)` | Глобальная векторизованная оценка плотности для всех облаков. Устанавливает `rho`, `P`, `cs`. Должна быть вызвана один раз за шаг до `cloud.update()`. |
| `_sph_kernel_w_vec(dist, h)` | Кубический сплайн ядра W(r,h) — векторизовано по массиву расстояний |
| `_sph_kernel_dw_vec(dist, h)` | Член градиента dW/dq для расчёта силы давления |

SPH длина сглаживания `SPH_H = 3.5`. Адиабатический индекс переключается: `γ = 4/3` (эпохи 0–1, радиация-доминируемые) → `γ = 5/3` (эпоха 2+, монатомный газ).

---

### Химия

| Функция | Описание |
|---------|---------|
| `assemble(b, nodes, epoch)` | Эпоха-зависимая химия облаков. Продвигает элемент по цепи `nu→e→p→H→He→...` в зависимости от температуры T и близости к узлам работы. Использует период иммунитета (`ASSEMBLY_GRACE_STEPS`) для предотвращения мгновенной диссоциации. Тяжёлые элементы (H+) никогда не распадаются обратно в nu вне поля узла. |
| `fuse(c1, c2)` | Ядерный синтез при столкновении облаков: продвигает c1 на один шаг вверх по цепи элементов |
| `collide(c1, c2)` | Проверка столкновения облако-облако; триггеры синтеза + термального смешивания |
| `collide_all_fast(world)` | Ускоренный проход коллизий по пространственной сетке для всех облаков |

**Пороги сборки** (МэВ-аналог, разделён на фактор силы узла):

| Переход | Порог |
|---------|-------|
| nu → e | 0.782 |
| e → p | 1.293 |
| p → H | 9.592 |
| H → He | 8.7 × 0.8 (скорость зависит от плотности) |

Выгорание (холодная диссоциация): `e` распадается если `T < 0.39`, `p` распадается если `T < 0.65`. Горячая плазма не выгорает — только холодная материя ниже порога образования.

### Жизненный цикл облаков

| Функция | Описание |
|---------|---------|
| `merge_clouds(world)` | Объединить перекрывающиеся облака (разделение < `CLOUD_MERGE_FRAC × (r1+r2)`). Консервирует массу, импульс, тепловую энергию. Окно иммунитета: облака с `_el_age < 0` защищены. |
| `split_cloud(world, epoch)` | Фрагментация Джинса: облака, превышающие `CLOUD_SPLIT_MASS = 5000`, раскалываются на две дочерних по 50% массы каждая, с лёгким охлаждением. |
| `evaporate_small_clouds(world)` | Удалить облака ниже `CLOUD_MIN_MASS = 5`. |

### Формирование структур

| Функция | Описание |
|---------|---------|
| `star_formation(world, bubbles, nodes, epoch)` | Формировать звёзды из облаков H вблизи доминирующих узлов (широкий радиус захвата, ниженный порог Джинса) или спутниковых узлов (стандартный порог). Pop III включена при эпохе ≥ 3. |
| `pop3_star_formation(world, bubbles, nodes, epoch)` | Первые массивные звёзды без металлов: масса > 40, rho > 0.01, вблизи любого узла. Усиление массы 1.5×, высокая температура зажигания. |
| `reionization_feedback(world, bubbles, epoch)` | Эпоха 4+: звёзды излучают УФ нагрев близлежащим облакам H/He. Фото-ионизация: H → p когда T превышает порог. |
| `galaxy_formation(world, bubbles, nodes, epoch, step)` | Отслеживать звёздные кластеры на пузырь. Гравитационно связывать звёзды к центру пузыря. Обнаруживать события коллапса. Засеивать дополнительные узлы в Космический полдень (эпоха 6). |

### Система узлов

| Функция | Описание |
|---------|---------|
| `update_nodes(nodes, world, epoch)` | Обновить все узлы: внедрить эпоху для масштабирования дрейфа, вычислить локальную плотность работы, затухание жизни. |
| `node_interactions_in_bubbles(bubbles, nodes)` | Доминирующие узлы отталкиваются друг от друга (радиус исключения 8). Спутниковые узлы в пределах `NODE_RADIUS` доминирующего поглощаются (+сила, -жизнь). |
| `node_gravity(world, nodes)` | Доминирующие узлы гравитационно привлекают собранную материю (H, He, звёзды) в пределах радиуса 12. Облака H очень близко к доминирующему узлу медленно аккрецируют массу. |
| `work_field_fast(b, nodes)` | Векторизованная сила поля работы на облако b от всех живых узлов в пределах `NODE_RADIUS`. |
| `local_work_density_fast(b, R=2.0)` | Плотность работы на позиции облака: сумма близлежащих значений `work` / объём. Используется для порога появления чёрной дыры. |

### Вселенная / Мультивселенная

| Функция | Описание |
|---------|---------|
| `spawn_multiverse(bubbles, world, nodes, step)` | **Зажигание пролёта узла**: быстро движущийся узел, проходящий через кластер облаков, откладывает энергию работы. Если `node_strength × speed × nearby_clouds > BUBBLE_FORMATION_COST`, пузырь загорается. Захватывает все близлежащие облака (энергетическое запирание), засеивает 4 внутренних узла. Кулдаун: 1 пузырь на 8 шагов, макс `MAX_BUBBLES = 12`. |
| `internal_nodes(bubbles, nodes)` | Каждый пузырь вероятностно засеивает новые узлы работы в своём интерьере (`INTERNAL_NODE_RATE`). Экзотические пузыри производят экзотические узлы. |
| `universe_evolution(bubbles, world, nodes)` | Энергетический баланс пузыря: истощение от внутренней работы + стоимость радиуса. Расти если энергия > 80, сжиматься иначе. Отметить мёртвым при энергии < 5. |
| `universe_feedback(bubbles, world)` | Пузырь излучает тепло во внутренние облака, включая химию даже далеко от внешних узлов. |
| `interact_universes(bubbles, world)` | Внутренние облака: лёгкое тепловое давление наружу. Внешние близлежащие облака: гравитационная притяжение внутрь (до 2.5× радиуса пузыря). |
| `decay_dead_universe(u, nodes)` | Мёртвые пузыри распадают внутренние узлы с типо-специфичными скоростями. |
| `framework_feed(world)` | Инъекция новых нейтринных облаков из глобального резервуара с `FEED_RATE`. Резервуар истощается со временем (`FRAMEWORK_DECAY = 0.00001`). |

### Чёрные дыры

| Функция | Описание |
|---------|---------|
| `spawn_black_holes(world, white)` | Проверить все облака на условие появления чёрной дыры: `local_work_density > 120` И `\|vel\| > 2.0`. Появляется макс одна чёрная дыра за шаг. |
| `accretion_fast(world)` | Все чёрные дыры аккрецируют облака в пределах `bh.radius × 2` используя пространственную сетку. |
| `merge_black_holes(world)` | Чёрные дыры в пределах `BH_MERGE_DIST = 1.2` объединяются (масса + тепловая энергия). |
| `explode_bh(bh, world)` | Чёрная дыра перегрета (`T > BH_EXPLODE_E = 200`): взрывается в 60 облаков nu. |

Три типа коллапса обнаруживаются автоматически в `galaxy_formation()`:

| Тип | Условие | Физический смысл |
|-----|---------|-----------------|
| `galactic_bh` | `peak_work_density ≥ 0.6 × CRITICAL` при растворении галактики | Центральная сверхмассивная чёрная дыра образована при коллапсе |

## Основной цикл

Минимальный главный цикл без Streamlit:

```python
import wtf_model as M
import numpy as np

world, white, nodes = M.create_universe()
bubbles = []
dt = 0.05

for step in range(1000):
    epoch = M.get_current_epoch(step)
    M._current_epoch = epoch

    # 1. Пространственный индекс
    M.spatial_hash.build(world)

    # 2. SPH плотность (должно быть до update)
    M.sph_density_pass(world)

    # 3. Подача + белая дыра
    M.framework_feed(world)
    white.process(world)

    # 4. Динамика
    for b in world[:]:
        if isinstance(b, M.WhiteHole): continue
        if isinstance(b, M.BlackHole): b.update_bh(world)
        else: b.update(world, dt, nodes, use_spatial=True, epoch=epoch)

    # 5. Химия
    for b in world:
        if not isinstance(b, (M.WhiteHole, M.BlackHole)):
            M.assemble(b, nodes, epoch=epoch)

    # 6. Коллизии + жизненный цикл облаков
    M.accretion_fast(world)
    world[:] = M.collide_all_fast(world)
    M.merge_clouds(world)
    M.split_cloud(world, epoch)
    M.evaporate_small_clouds(world)

    # 7. Чёрные дыры
    M.merge_black_holes(world)
    M.spawn_black_holes(world, white)

    # 8. Вселенная / мультивселенная
    M.spawn_multiverse(bubbles, world, nodes, step=step)
    M.internal_nodes(bubbles, nodes)
    M.update_nodes(nodes, world, epoch=epoch)
    M.node_interactions_in_bubbles(bubbles, nodes)
    M.universe_evolution(bubbles, world, nodes)
    for u in bubbles:
        M.decay_dead_universe(u, nodes)

    # 9. События эпохи (звёзды, галактики, реионизация)
    M.cosmic_epoch_events(world, bubbles, nodes, step)

    # 10. Обратная связь + гравитация
    M.universe_feedback(bubbles, world)
    M.interact_universes(bubbles, world)
    M.node_gravity(world, nodes)

    # 11. Граничные условия
    for b in world:
        M.phase_walls(b)
    M.space_decay(world)
```

## Обнаружение коллапса

Двигатель автоматически регистрирует события коллапса галактик. Доступ в любое время:

```python
import wtf_model as M

# Все события
for event in M.COLLAPSE_LOG:
    print(event["step"], event["type"], event["peak_density"])

# Фильтр по типу
bh_collapses = [e for e in M.COLLAPSE_LOG if e["type"] == "galactic_bh"]
direct       = [e for e in M.COLLAPSE_LOG if e["type"] == "direct_collapse"]
agn          = [e for e in M.COLLAPSE_LOG if e["type"] == "agn_flare"]
```

Пиковая плотность работы при коллапсе — ключевой диагностический показатель:
- `peak_density ≥ 72` (60% критичного 120) → `galactic_bh` — центральная чёрная дыра подтверждена
- `peak_density < 72` + быстрая потеря звёзд → `direct_collapse` — приливная дизруптация или потеря материала без стадии чёрной дыры
- Это различие соответствует наблюдаемому поведению итерация ~1488: малый пик сингулярности при растворении галактики = галактическая чёрная дыра, не полный сингулярный события

## Известные ограничения

### Что модель хорошо захватывает
- Тепловая смерть / смерть теплом вселенной (подтверждено, стабильно без новой энергии)
- Эпоха-последовательное формирование структур (нейтрино → H → He → звёзды → галактики в правильном порядке)
- Нестабильность галактики и дизрапация с образованием центральной чёрной дыры
- Инфляционно-подобное расширение, за которым следует сжатие когда внутренние узлы потребляют всю материю
- Край-предпочтительное распределение узлов после расширения (согласуется с наблюдениями космической паутины)
- Перекрытие пузырей с различной внутренней структурой (прото-мультивселенная)

### Фундаментальные ограничения

**Только физика, основанная на Земле.** Все пороги, цепи элементов и константы взаимодействия выводятся из наблюдаемой физики частиц в нашей локальной вселенной. Модель не может представлять:

- Альтернативную физику частиц в перекрывающихся пузырях вселенной, где физические константы могут отличаться
- Поведение на подпланковских масштабах
- Физику сильного/электрослабого объединения
- Квантовые эффекты (модель — классическая SPH)

**Зависимость от параметров.** Формирование структур сильно зависит от параметров. Без иерархии 4 доминирующих узлов и энергетического запирания при зажигании пузыря, вероятность случайного образования приближается к нулю. Это может отражать реальную проблему тонкой подстройки или может указывать на отсутствующую физику, обеспечивающую надёжность.

**Стабильность галактик.** Галактики из 7–12 звёзд образуются и растворяются циклически. Механизм дизруптации создаёт пики плотности работы, согласующиеся с образованием центральной чёрной дыры. Является ли это представлением реальной динамики галактических слияний или артефактом модели, окончательно не разрешено.

**Масштаб.** Одна единица симуляции не откалибрована в физические единицы (AU, парсек, МэВ). Пороги элементов (`TH_NU_E = 0.782`, и т.д.) установлены в МэВ-аналоговые значения, но пространственные и временные масштабы произвольны. Откалибровка в физические единицы потребует сопоставления синхронизации эпохи с действительными космологическими временами.

### Особенности интерфейса Streamlit
- **Режимы Step / Run / Batch / Live**
- **Баннер эпохи** с прогрессом до следующей эпохи
- **6-панельный график**: полная работа, кол-во чёрных дыр, порог плотности работы, эволюция узлов, уровень резервуара, звёзды и галактики по эпохам
